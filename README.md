# AI Chat

Чат с AI в духе ChatGPT для iPhone. Приложение на SwiftUI, работает с OpenRouter и потоковым ответом.

## Время работы

- Старт: 12.11.2026, 20:27 (МСК).
- Окончание: фиксируется при сдаче.

## Инструменты и модели

- Xcode и iOS Simulator (сборка и проверка на macOS).
- XcodeGen (проект описан в `project.yml`).
- Claude Code в облачной сессии (агент разработки). Сводка работы — в `ai-logs/summary-of-work.md`; сырые логи сессии в архив не входят, см. `ai-logs/README.md`.

## AI в приложении

- Сервис: OpenRouter, Chat Completions API (`https://openrouter.ai/api/v1/chat/completions`), потоковый режим (`stream: true`).
- Модель: `openrouter/free` (роутер бесплатных моделей). Меняется в `.env` через `OPENROUTER_MODEL`, без правки кода.
- Заголовок `X-Title`: «AI Chat».

## Что сделано

- Чат с AI с потоковым выводом по мере генерации и кнопкой «Стоп».
- Частичный ответ сохраняется после остановки или ошибки.
- Несколько чатов: создание, переключение, удаление с подтверждением, автоназвание по первому сообщению.
- История хранится в SwiftData и открывается после перезапуска.
- Состояния ошибок: нет сети, неверный ключ, лимит, ошибка сервера. Кнопка «Повторить» переиспользует то же сообщение.
- Пустой экран нового диалога.
- Markdown: заголовки, списки, блоки кода, разделители, строчный код, жирный и курсив.
- Светлая, тёмная и системная темы; выбор сохраняется.
- Тесты: 31 unit-тест (XCTest) для моделей, ViewModel, сети, SSE, тем и Markdown.

## Что не сделано и известные баги

- Если переключить чат во время генерации, ответ в старом чате дописывается до конца.
- Таблицы Markdown и вложенные списки не поддерживаются, выводятся как текст.
- Повтор заменяет частичный текст неудачного ответа, он не сохраняется отдельно.
- Ключ API обфусцирован, но не зашифрован. Маска лежит в приложении, поэтому ключ можно извлечь из собранного приложения. Для учебного задания это принятый компромисс.
- Ключ OpenRouter, переданный в переписке с агентом, не перевыпущен по решению владельца.
- Не сделано из необязательного: фото во вложениях, версия для Mac, офлайн на Apple Foundation Models.
- Предупреждение Swift 6 про `KeyPath` в `SwiftDataChatRepository.swift`. Сборка не ломает, но код ещё не приведён к строгому режиму.

## Как проверяли

- `Cmd+U` в Xcode: 31 тест, 0 ошибок.
- Ручная проверка на iOS Simulator: отправка, поток, остановка, ошибки и повтор, перезапуск, история, удаление, темы.
- Сборка через `Build.command` на macOS.

## Как собрать

1. Установите Xcode и XcodeGen: `brew install xcodegen`.
2. Скопируйте `.env.example` в `.env` и вставьте свой ключ OpenRouter в `OPENROUTER_API_KEY`. Файл `.env` не попадает в git.
3. Дважды щёлкните `Build.command` в Finder. Скрипт создаст файл с обфусцированным ключом, сгенерирует проект и соберёт приложение под iOS Simulator.
4. Путь к `.app` выводится в конце. Результаты сборки лежат в `~/Library/Developer/AIChatBuild`: внутри папки проекта сборка падает, если она синхронизируется через iCloud.

Без ключа приложение собирается, но запросы к модели возвращают ошибку «API-ключ не настроен».
