# Исходное техническое задание

Источник: «Тестовое задание: AI-ассистент для iPhone» (файл в проекте Claude «AI Chat») и раздел 1 master prompt.

## Задача

Сделать небольшое приложение — AI-чат в духе ChatGPT для iPhone. Писать с помощью AI-инструментов (Claude Code, Codex, Cursor, ChatGPT и др.). Важно видеть, как работаем с LLM и какое приложение получается.

## Обязательные функции

1. Чат с AI: ответ появляется по мере генерации (streaming), есть кнопка «Стоп».
2. Несколько чатов; история сохраняется после перезапуска.
3. Создание новых диалогов, удаление диалогов.
4. Понятные состояния: загрузка, ошибка (нет сети, кончился лимит API) с кнопкой «Повторить», пустой экран нового диалога.
5. Обработка ошибок сети, ошибок API и исчерпания лимитов.
6. Кнопка повторной отправки запроса.
7. Аккуратный интерфейс в духе iOS, светлая и тёмная темы.
8. Сохранение частично полученного ответа после остановки генерации.

## Желательно

- Markdown (заголовки, списки, блоки кода).
- Корректная работа клавиатуры, автоскролл.
- По желанию (не в объёме текущей работы): фото во вложении, версия для Mac, офлайн-режим на Apple Foundation Models для iOS 26+.

## Технические требования

- Минимальная версия iOS — 18.0; приложение работает на iOS 18 и на последней iOS.
- Swift, SwiftUI, MVVM, Swift Concurrency (async/await), URLSession, SwiftData.
- Проект на XcodeGen (`project.yml`).
- В корне файл `Build.command`: двойной клик в Finder запускает `xcodegen generate` и сборку под симулятор без ручных команд в терминале.
- Зависимости — только через Swift Package Manager. CocoaPods не используется.
- API, доступные только в новых версиях iOS, — с проверкой доступности и альтернативой для iOS 18.

## AI внутри приложения

- Облачный API: OpenRouter (основной выбор).
- Ключ в проекте в обфусцированном виде, не открытым текстом. Приложение запускается сразу после сборки, без настроек.
- Проверить, что у ключа остаётся бесплатный лимит на проверку.

## Требования к поставке

Архив (zip) всей папки проекта вместе с `.git`. В архиве:

1. Проект, который собирается двойным кликом по `Build.command`. Коммиты по ходу работы, а не один коммит в конце.
2. Документация, по которой велась работа с AI: описание задачи, план, правила для агента (`CLAUDE.md` и т. п.) — в том виде, в каком реально использовались. Описание и план — в `docs/`, файлы правил — там, где их читал агент.
3. Папка `ai-logs/` с историей работы с AI. Claude Code: `~/.claude/projects/` (папка проекта). Codex: `~/.codex/sessions/`. Cursor и браузерные чаты — экспорт или ссылки. Из логов удалить ключи и личные данные.
4. `README.md` по шаблону: время работы; инструменты и модели; AI в приложении (сервис и модель); что сделано; что не сделано и известные баги; как проверяли; как собрать.
